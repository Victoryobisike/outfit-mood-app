# Outfit Mood Recommender

A simple web application that suggests outfits based on the user's mood.

## Features
- Select a mood (lazy, confident, soft)
- Get an outfit recommendation instantly

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
The user selects a mood from a dropdown. JavaScript processes the input and displays a corresponding outfit suggestion.

## Future Improvements
- Add more moods and outfit variations
- Include images for each outfit
- Integrate AI for smarter recommendations
